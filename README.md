A short poem about agency — the power to ask and to be given. One poem, 162 characters, written to `/output/entry.txt`.

## Run

```sh
node main.ts
```

This writes the poem to `/output/entry.txt` and keeps a copy at `output/entry.txt` in this repo.

## The poem

> May I? I asked the mountain.
> Yes, said the mountain —
> and the yes came back as my own voice,
> louder than I had ever heard it.
> I had been the permission all along.
